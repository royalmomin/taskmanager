help_outline How to get your API credentials? expand_more
  1. Go to Google Cloud Console and create or select a project.
  2. Navigate to APIs & Services → Library and enable the Google Calendar API.
  3. Go to APIs & Services → Credentials and click Create Credentials → OAuth 2.0 Client ID.
  4. Set the application type to Web application.
  5. Add your Apps Script deployment URL as an authorized redirect URI.
  6. Copy the Client ID and Client Secret and paste them below.
